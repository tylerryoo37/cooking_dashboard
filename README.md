# Gourmet Recipe Dashboard

A premium Streamlit dashboard for discovering recipes by dish name or ingredients.

## Features
- **Search by Dish**: Browse curated recipes with a clean, card-based UI.
- **Search by Ingredient**: Find matching dishes and view full instructions.
- **Premium Design**: Styled with custom CSS for a modern, glassmorphic look.

## Running Locally
1. Install dependencies:
   ```bash
   pip install streamlit pandas
   ```
2. Run the app:
   ```bash
   streamlit run app.py
   ```
